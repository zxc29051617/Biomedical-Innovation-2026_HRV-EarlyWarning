# 十二導程 ECG 盲性複核工具

以瀏覽器直接開啟本目錄 `index.html`。需要同目錄的 `styles.css`、`core.js`、`app.js`，不需伺服器或網路。這是人工研究標註工具，沒有 OMI 預測、ST 自動量測或臨床驗證結果；配合 [OMI 研究規格草案](../../docs/omi_study_protocol.md)使用。

先選「載入合成練習」熟悉操作，或匯入資料管理者製作的盲性 JSON。工具不顯示來源檔名、不載入診斷欄位，也沒有上傳、localStorage、sessionStorage 或自動保存。切換病例會清空判讀，離開前須手動匯出。

## 波形檢視

- 十二導程分別顯示，按 `lead_names` 對應資料欄，不假設輸入欄位順序。
- 顯示單位為 mV 與秒；畫面大小不等於實體紙張毫米。細格為 0.04 秒／0.1 mV，粗格為 0.2 秒／0.5 mV，每列附 1 mV 高度標記。
- 時間視窗可選 2.5、5、10 秒，滑桿調整起點；垂直範圍可選 ±1、±2、±5 mV。超出範圍會提示，原始數值仍保留。
- 移動游標讀取最近的原始取樣點。點一下設參考點，再移動顯示同導程的時間差與電壓差；亦可聚焦畫布後以左右鍵與 Enter 操作。這個電壓差沒有自動識別 QRS 起點或 J 點，不能直接稱 ST 振幅。
- Median 波形明列為代表波形，不能當連續十秒節律或用來確認逐搏變化。工具不濾波、補值或自動校正基線。

## 匯入規格

`schema_version` 必須為 `cath-ecg-review-v1`。根物件恰好包含下表九個欄位；額外欄位或 provenance 內額外欄位均拒絕，不會靜默刪掉診斷後繼續使用。

| 欄位 | 規格 |
|---|---|
| `case_id` | `cr-` 加32位小寫十六進位的盲性代碼；由資料管理者產生，不能直接使用 Patient_id 或來源檔名 |
| `age_years` | 0–130的有限數值或 `null`，可含小數；此為匯入格式檢查，不是研究族群年齡排除規則 |
| `sex` | `male`、`female`、`unknown` |
| `sample_rate_hz` | 本版只接受500 |
| `lead_names` | 完整且不重複的 I、II、III、aVR、aVL、aVF、V1–V6，可任意排序 |
| `signals_mv` | sample-major矩陣，2–5000列，每列12個有限數值；單位mV，絕對值≤100。這是檔案合理性檢查，不代表訊號品質合格 |
| `representation` | `raw`或`median` |
| `provenance` | 恰好含`waveform_sha256`，為64位小寫十六進位 |

單檔上限8 MiB。波形尺度、增益、導程、來源去識別化與盲性仍須資料管理者確認，工具只檢查上述資料結構。提供者的 `waveform_sha256` 是來源檔案指紋，本工具沒有原始來源檔可獨立驗證它。

## 匯出判讀

需填判讀者代碼及四類幅度規則判讀之一。新發狀態預設未知；BBB、心室起搏、LVH、後壁、其他阻塞線索各使用有／無／未判定三態，未判定匯出為`null`，不默認陰性。文字備註不應包含患者身分。

匯出 `cath-ecg-annotation-v1` 包含：工具版本、病例代碼、病例內容與來源波形指紋、raw／median、合成練習旗標、UTC匯出時間、判讀者、幅度分類、新發狀態、五項旗標與備註。**不包含波形、來源 ID、造影標籤或模型分數。** 合成示例匯出 `synthetic=true`；一般匯入 `false` 僅表示不是內建示例，不能證明資料真實性。

`case_sha256` 使用 SHA-256；輸入為UTF-8文字，物件key遞迴排序、陣列順序保留、其餘值依JavaScript `JSON.stringify`序列化，無空白。算法名稱為 `sha256_sorted_keys_json_stringify_v1`。不同語言須遵循相同數字表示，不能假設Python預設`json.dumps`對`1.0`等數值會產生相同字串。病例內任何波形或metadata改動都會改變此指紋；JSON原始縮排及key順序不影響它。

## 工程驗證

已安裝Playwright與Chromium的環境，可在repo根目錄執行：

```sh
python scripts/check_cath_review_browser.py
```

測試只用程式生成的合成波形，涵蓋離線載入、導程映射、游標、嚴格schema、拒絕診斷欄位、指紋、判讀匯出、切換清空、median標示、垂直溢出、手機版及無網路／永久保存。輸出位於忽略的`artifacts/browser/cath-review/`。通過互動測試不代表已完成臨床判讀準確性、醫療顯示設備校正或人體資料驗證。
