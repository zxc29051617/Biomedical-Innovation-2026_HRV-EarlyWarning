# 同一參考搏動集合上的量測對照

2026-11-01，`shared_reference_timing_v0.1.0`。這是看過[第一輪 MIT-BIH 工程 pilot](beat_timing_validation.md)後提出、在執行本輪對照前寫下的描述性追蹤規格。六筆資料已參與方法開發，這次不能稱新的獨立驗證，也不會改動定位候選、品質規則、M2 快取、患者切分或預警保留測試。

## 要釐清的問題

第一輪各方法在自己成功匹配的搏動／相鄰片段上計算誤差；候選棄權較多，保留下來的子集不同。因此先比較同一批參考搏動，釐清較小的條件誤差有多少來自定位改變，同時保留完整的漏搏與棄權代價。共同支援上的改善仍不能代替整體改善。

## 固定比較規則

資料、導程、全部非重疊五分鐘窗、原生及 125 Hz、XQRS 種子、候選版本及參數均與第一輪相同。人工審閱標註保留原始秒數，不先量化到 125 Hz。使用原 `match_beats` 的一對一配對：先最大化匹配數，再最小化總絕對時間差，100 ms 配對界線與 1e-12 秒數值餘量不變。

1. 搏動時間：取兩方法皆匹配到的參考搏動編號交集，兩方法在同一個參考時間上計算偏差及絕對誤差。
2. RR：除了上述共同參考搏動，兩搏還必須在參考序列、原始 XQRS 種子序列、候選保留的原始種子序列三者中皆相鄰。漏搏、多餘偵測與候選棄權都會中斷鄰接，不能刪掉後補接。
3. RR 變化與 RMSSD：使用同時滿足前項的共同原始相鄰三搏。比較的是這些共同三搏的 RR 差值平方平均根，不能稱整段五分鐘 NN-HRV 精度。
4. 同時呈現全體參考搏動、每法偵測／匹配／漏搏／多餘搏動數、候選棄權及共同支援比例。沒有共同三搏時 RMSSD 留空，不記成零誤差。
5. 較小誤差以 candidate−baseline 的同點絕對誤差差值表示；負數代表共同支援上的條件改善。先在各窗計算，再呈現逐窗差值中位數，不能用兩個邊際中位數相減代替配對差值。各窗 p95 的中位數也不是 pooled p95。

所有 72 組評估都保留，失敗窗及原因明列；逐取樣率、逐紀錄呈現。同一個紀錄的兩種取樣率不是獨立病例。六筆記錄只作描述，這輪不做顯著性檢定、不新增合格門檻、不依結果挑例或調參。額外核對本輪每法的偵測數、匹配數及全種子保留窗數是否精確重現上一輪；若不一致，保存報告但讓程序失敗，先找原因。

## 執行

```sh
PYTHONPATH=src python -m unittest discover -s tests -p test_timing_comparison.py -v
python scripts/download_reference_ecg.py --output-dir artifacts/rr_validation/reference
PYTHONPATH=src python scripts/compare_reference_timing.py \
  --manifest artifacts/rr_validation/reference/manifest.json \
  --output-dir artifacts/rr_validation/paired
```

核心交集與指標程式只需標準函式庫；真實 ECG 重跑需 `signal` 依賴。已有官方 manifest 時不重複下載；原始資料及結果只寫入忽略目錄，輸出存在則拒絕覆寫。報告為 `paired_timing_summary.json`，包含來源、方法、規格雜湊、逐窗／逐紀錄結果與彙總；stdout 提供 `PAIRED_TIMING_SUMMARY_JSON=`，不含波形、ICU 資料或個別搏動時間。

本文件定稿時尚未取得本輪真實結果；合成測試只證明程式在已知反例的行為，不能冒充實測準確度。實際結果由 CI 完成後另行記錄。

## ICU 雙人盲標的最小試行

沿用先前規格：20 名不同的訓練患者，各固定一個五分鐘窗，v1 accepted／rejected 各 10 例。依預先固定的雜湊排名選例、保存私有 manifest，排除已看過的六例回歸樣本；不根據終點、模型分數或候選改善大小挑選。若某組不足，直接報不足，不從 validation 或 test 補人。這個人工配額只用來測試標註流程，不用來估計全體準確率。

兩位具 ECG 判讀能力、各自有資料使用權限的審閱者，在本機獨立判讀同一導程。第一階段不顯示模型分數、給藥終點、v1 接受狀態或任何偵測器點位；可調整縮放，但顯示取樣率與毫秒刻度。保存各自原始標註，不以後來共識覆寫。

| 標註層級 | 最小必要欄位 |
|---|---|
| 片段 | 匿名片段代號、導程、取樣率、原始資料雜湊、標註版本、審閱者代號 |
| 訊號區間 | 可判讀／雜訊／缺資料／未知；起訖樣點；不把無法判讀默認為無搏動 |
| 搏動 | 每個可辨識 QRS 的一致定位點樣點、搏動類別、把握度；多峰或寬形態記定位不確定範圍 |
| 節律區間 | 經判讀的竇性／AF 或 flutter／pacing／其他／未知，及起訖；保留無法判定 |
| NN 資格 | 由搏動與節律一起判定可使用區間及理由；單一 `N` 標籤不自動通過，不插補未辨識搏動 |
| 分歧與共識 | 雙人搏動配對差、定位差、類別與節律分歧；共識／第三位審閱者的修訂理由 |

正式標註前，審閱者需先共同寫定「一致定位點」在正向、反向、多峰與寬 QRS 的操作規則，再以不屬於 20 例的教學片段練習。不要讓審閱者以讓 RR 變平滑為目標移動定位點。原取樣率、跨導程差與人工不確定性都要保留；125 Hz 的一個樣點是 8 ms，不能從顯示上的游標小數偽造更高的原始精度。

先報審閱者間一致性，再對照凍結演算法；尚無共識或無法可靠定位的片段保留未知。正常 NN 必須有適用的搏動及節律依據，不能直接將全部 RR 當 NN。這個區別承接 [ESC／NASPE 的 HRV 量測標準](https://www.escardio.org/static-file/Escardio/Guidelines/Scientific-Statements/guidelines-Heart-Rate-Variability-FT-1996.pdf)；雙人獨立審閱及共識的參考做法見 [MIT-BIH 官方標註說明](https://physionet.org/physiobank/database/html/mitdbdir/intro.htm)。20 例、配額、盲標欄位及操作流程均是本研究的試行設計，不是臨床標準或已完成結果。
