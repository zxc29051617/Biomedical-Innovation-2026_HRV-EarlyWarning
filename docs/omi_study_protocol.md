# 造影前十二導程 ECG 急性冠脈阻塞辨識研究規格

版本 0.1，2026-11-02。使用者已支持以全部 OMI 開發模型，並預先指定未達一般 ST 上升門檻的關鍵次要子群。本文件固定研究問題與評估原則；**尚未完成臨床判讀規則、index ECG 選擇及樣本精度審查，因此是開發前草案，尚非完整凍結或正式預先登錄的計畫。** 本輪沒有訓練 OMI 模型。舊 HRV protocol 0.3、結果、患者切分與保留測試均維持原狀。

## 研究問題與目前可驗證的範圍

工作題目為「造影前十二導程 ECG 急性冠脈阻塞辨識：一般 ST 上升門檻之外的增量價值」。核心問題是：在同一張 ECG 上，模型能否補捉一般 ST 上升幅度規則未辨識的急性阻塞，以及增加多少偽陽性？全部 OMI 的 AUC 不能單獨回答此問題，也不能證明降低死亡或減少不必要心導管。

第一階段使用 ACS-ECG 公開資料。主要參照標準忠實沿用其既有 `OMI` 標籤：**急性罪犯血管閉塞，PCI 前 TIMI 血流分級 0 或 1**。不自行改成 `AMI AND PCI`、不把 CTO 當急性閉塞，也不額外要求 `AMI=1 AND OMI=1`。陰性只表示來源此定義的陰性，不保證沒有已再通的 OMI。[資料原文 Methods、Limitation](https://www.nature.com/articles/s41597-026-07278-0)

訓練納入符合資格的全部來源 OMI 陽性及陰性，不按來源 STEMI／NSTEMI 診斷或後續的波形子群挑選訓練病例。主結果稱為「資料集定義的急性阻塞辨識」，不宣稱已驗證所有臨床 OMI。

## OMI 定義的原始文獻核對

| 來源 | 實際定義與差別 | 本階段能否重建 |
|---|---|---|
| [Herman 等，ztad074，Outcomes／Table 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC10944682/) | MI 臨床及 troponin 條件，加上急性 culprit TIMI 0–1，或 TIMI 2–3 且接受緊急／急迫 PCI；高 troponin cutoffs 是另列的次要終點 | 否；主定義仍部分涉及治療決策，不能說完全不受決策影響 |
| [JACC Advances 2026，102663，Outcomes](https://pmc.ncbi.nlm.nih.gov/articles/PMC13053991/) | 造影有 culprit lesion，且〔TIMI 0–2，或 TIMI 3／unknown 並符合高峰 troponin／室壁運動條件〕；完整條件見下段 | 否；可作後續臨床驗證採用的已發表 composite |
| [ACS-ECG，Scientific Data 2026](https://www.nature.com/articles/s41597-026-07278-0) | 急性 culprit、介入前 TIMI 0–1；作者明列無 adjudicated OMI、無法納入再通的寬定義 | 可使用既有標籤；缺乏原始證據供本團隊逐案重新裁定 |

上述定義不可當成同一個通用終點，也不能直接以不同族群、終點及閾值的 AUC 排名模型。

後續臨床驗證預定採 JACC Advances 2026 的 composite；取得資料後、看模型成績前，將全文轉為逐案裁定表並凍結。造影有 culprit lesion 是必要條件；對 TIMI 3／unknown 分支，還需血運重建前高峰 troponin 達門檻，或高峰缺失／低於門檻且有 assumed new RWMA。門檻分別是 hs-cTnT ≥1,000 ng/L、hs-cTnI >5,000 ng/L、conventional cTnI >10.0 ng/mL、conventional cTnT >1.0 ng/mL。保留 assay、單位、時間與不等號，不能用術後高峰或「AMI＋PCI」代替。現有 CSV 缺原始 TIMI、troponin、assay 與 echo；欄位未公開也不等同原研究已裁定的 TIMI unknown。**目前不產生此 composite 標籤**。[原文 Outcomes](https://pmc.ncbi.nlm.nih.gov/articles/PMC13053991/)

## 族群與 index ECG

公開資料的母群為已接受冠狀動脈造影者，包含非 ACS 病例；不能直接改稱「疑似 ACS」或一般急診胸痛母群。若後續取得可驗證的疑似 ACS 納入資料，另訂該族群。誰接受造影、多久後接受造影都受臨床決策影響，存在選擇及驗證偏差；PPV／NPV 只能連同本研究盛行率解讀。

臨床驗證希望一律選同次就醫到院後、介入前的第一張十二導程 ECG，所有結局使用相同規則；不能對 STEMI 選觸發心導管的 ECG，對其他患者另選一張。該張品質不合格即記錄無法評分，不另選較晚 ECG。

**目前公開欄位無到院時間、ECG／造影絕對時間及 encounter／procedure ID。** `Time_Interval` 只代表距造影分鐘數；最小值不等於第一張到院 ECG，最大值也不能證明第一張屬於同次事件。同患者多張是否來自同次急性事件仍待釐清。因此「首次到院 ECG」目前不能實作，也不能對外如此描述。

在取得事件關聯前，公開資料最多可作每份造影前 ECG 的工程基準，全部同患者資料留在同一分組，信賴區間以患者為叢集；不能把每份 ECG 當獨立患者。正式主分析的單次事件／單張 ECG 規則需先補齊資料並凍結；若無法補齊，公開基準的分析單位明列為 ECG，單張病例檢出數也只能稱紀錄數，不能冒稱病人數或到院分流效果。

既有 0–60、>60–360、>360–1,440、>1,440–10,080 分鐘為固定可行性分層，均呈現，不按模型成績挑時間窗。主要時間資格需在模型開發前另行凍結；距造影時間不得當作當下模型輸入。

## 同張 ECG 的一般 ST 上升對照

主要比較欄位命名為 `index_ecg_ste_amplitude_status`，指模型輸入同張 ECG 的一般 ST 上升幅度規則，**不等同完整臨床 STEMI 診斷**。ST 段是 QRS 波結束到 T 波開始之間的一段；本規則量測位置為 J 點，不能換成 J 點後 60–80 ms。

至少兩個解剖相鄰導程各自達到其門檻；在已確認標準尺度下，1 mm = 0.1 mV：

| 導程及條件 | J 點門檻 |
|---|---:|
| V2–V3，男性 <40 歲 | ≥2.5 mm |
| V2–V3，男性 ≥40 歲 | ≥2.0 mm |
| V2–V3，女性 | ≥1.5 mm |
| 其餘一般十二導程 | ≥1.0 mm |

數值依 [2018 Fourth UDMI，§27／Table 2／Figure 8](https://doi.org/10.1093/eurheartj/ehy462)及 [2025 ACC/AHA ACS，Table 3](https://www.jacc.org/doi/10.1016/j.jacc.2024.11.009)。截至本版日期，已有 [2026 Fifth UDMI](https://doi.org/10.1093/eurheartj/ehag101)；其 [§13 正文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13523810/)保留相同一般門檻，不能將 2018 版稱為最新版本。本研究固定以上一致數值，不直接從新版 Table 5 的年齡文字轉錄程式。

2018 Figure 8 的 J 點位移參考為 QRS 起點電位。波形單位、增益、導程順序、QRS 起點與 J 點可靠性必須先驗證。完整相鄰導程配對表、LVH／BBB 判定及量測工具版本尚待心臟科審查後寫入標註手冊；不能由任意兩個導程超標便判陽性。

研究分類預先分為四類：

1. 適用且可量測，達一般 ST 上升幅度門檻。
2. 適用且可量測，未達一般 ST 上升幅度門檻。
3. 需另外規則判讀：BBB、心室起搏、LVH 等；記錄各項原因，不自動歸陰性。
4. 無法判定：尺度不明、缺必要導程、雜訊或 J 點不可靠等。

此四類是研究操作分類。LBBB 單獨不構成 STEMI；BBB／心室起搏及後壁型態另有指引處理方式。[2025 ACS Table 3](https://www.jacc.org/doi/10.1016/j.jacc.2024.11.009)、[2023 ESC ACS §3.2.1](https://doi.org/10.1093/eurheartj/ehad191)

後壁疑似型態與其他阻塞線索另設旗標；若標準十二導程一般幅度可判且陰性，可保留於第 2 類，但要分層報告。沒有 V7–V9 不能當已排除後壁梗塞，亦不能將這些病例稱為「所有傳統 ECG 判讀都漏掉」。Sgarbossa 等另列判讀規則，不混進一般毫米對照。

`newness` 另記為 new／presumed_new／old／unknown。缺先前 ECG 不能自動宣稱已確認新發；單張幅度結果與臨床新發缺血判斷分開保存。缺必要年齡／性別時保留無法套用門檻的狀態，不擅自補預設值。

兩位判讀者獨立判讀，僅見匿名 index ECG 及套門檻必要的年齡／性別；不知道造影、來源 OMI／STEMI／NSTEMI、PCI、troponin 或模型分數。分歧交由第三位具心電圖判讀資格的臨床人員裁決。自動 ST 量測可作輔助，但需先固定版本並與盲判核對；目前無已驗證的自動量測結果。判讀前固定抽查與一致性報告方式，來源診斷欄位不能代替此程序。

## 評估與閾值

| 層次 | 分析內容 |
|---|---|
| 主分析 | 所有合格且模型可評分的來源 OMI 陽性／陰性之 AUROC、AUPRC、校準與固定閾值混淆矩陣；另報全部資格病例的可評分率與未評分陽性數 |
| 必要臨床對照 | 在同張 ECG、一般幅度規則可判且模型可評分的交集，並列模型與規則的敏感度、特異度、PPV、NPV及分母，同時報排除數與其 OMI 數 |
| 關鍵次要分析 | 第 2 類「適用且未達門檻」中，固定模型閾值的敏感度、偽陽性率、PPV及95%信賴區間，並列實際 TP／FP／FN／TN |
| 預先指定描述分析 | 第 1、3、4 類、時間分層、後壁／其他阻塞線索、年齡與性別；不從中挑最高分當主要結果 |

以 `Y` 為來源 OMI、`S` 為一般幅度規則陽性、`M` 為固定閾值模型陽性，在共同適用集合報告：

- 額外抓到：`Y=1, S=0, M=1`。
- 額外偽陽性：`Y=0, S=0, M=1`。
- 若考慮由模型取代規則，另報 `Y=1, S=1, M=0` 等所有不一致格，不能只呈現新增檢出。
- 加成策略 `S OR M` 與 `S` 使用相同分母，並列每 1,000 個可評估單位的新增 TP／FP；ECG 與患者／事件單位分開，不互換。這只是回溯分類負擔，尚不等於實際增加多少次心導管。

關鍵子群同樣報模型可評分集合的效能，以及全部第 2 類的拒答數／陽性數。另在全部規則可判集合評估加成策略時，模型拒答則維持 `S` 結果，並保留拒答旗標，不視為模型已判陰性；規則也無法判定者維持不確定，不硬補陰性。這個回溯策略不代表已授權臨床自動處置。

閾值只在開發校準資料選擇，不能由測試 ROC 選最漂亮的點。暫定研究操作點為校準陰性中的偽陽性率不超過 5%，在滿足者中選敏感度最高者；同分選較高閾值，判定使用 `score >= threshold`。此為研究設計選擇，非指引的臨床容許值；數值與平手規則在正式模型計畫一併凍結。若無非平凡閾值可滿足條件，照實報告，不在驗證資料放寬。

同一閾值適用全部及各子群，不為未達 ST 門檻子群重新調整。驗證時實際特異度可能偏離 95%；一般 ST 對照的特異度也可能不同，必須並列，不能直接稱「相同誤報負擔下較佳」。整體高 AUC、敏感度增高伴隨大量額外 FP，均不足以單獨宣稱臨床改善。

## 患者切分與可得資訊

所有同一患者 ECG 必須在同一分組。公開 train 內的開發、校準與保留驗證分組，在模型擬合前固定並保存雜湊；比例需先依最終陽性患者及關鍵子群數完成精度規劃，不在看模型表現後重新分組。預處理、模型選擇與校準只在開發部分進行。保留驗證僅在模型、閾值及分析程式凍結後開啟；一旦使用其結果改模型，此集合即降為開發資料。

官方 test 的疾病標籤未公開；目前不能離線取得官方測試效能。作者平台可用性及可回傳的子群指標尚未確認，不能將官方測試成功當既定資源。即使能查官方分數，也不得反覆查分調參。

主要候選輸入為原始十二導程波形；當下可確認的年齡／性別若加入，須另列與 ECG-only 的對照。OMI、STEMI、NSTEMI、AMI、PCI、CTO、病變位置、造影時間間隔、ECG 自由文字診斷、後續 troponin／echo 均不得混入即時特徵。補值、標準化與特徵選擇僅使用訓練患者；後續檢查可判定結局，不能倒灌為輸入。

保留驗證的配對差值以患者為單位共同 bootstrap 2,000 次，固定 seed 20261102，保留同患者全部 ECG，報95%百分位區間及單一類別抽樣的無效次數。若最終主分析確為一患者一事件，另報敏感度／特異度的 Wilson 95% 區間；多 ECG 不使用假定各列獨立的二項區間。各子群估計不作已校正的多重顯著性主張。

## 樣本可行性與開始建模前的條件

公開 train 有17,960份 ECG、17,018個 Patient_id。[第二輪實際 metadata 稽核](results/cath_metadata_patient_summary.json)確認：來源 OMI=1有1,151列／1,139位患者；同列 `OMI=1 AND source STEMI=0` 有424列／418位患者；115位患者於不同列有OMI=0與1，尚不能合併為同次事件。**418位來源診斷交集患者不能當第2類關鍵子群的樣本數。** 同張波形尚未判讀，不使用「少數特殊病例」描述未知比例。

關鍵次要子群要在同張 ECG 盲判後，分別數獨立患者／事件與 ECG，並報其於保留驗證的陽性數。樣本規劃以敏感度區間精度為依據，先看分母再決定是否能作正式結論；不能以總訓練 OMI 筆數代替。例：30 個獨立陽性中抓到21個，敏感度70%，Wilson 95%區間約52.1%–83.3%。這是精度示例，並非本研究結果。

若精度不足，仍完整報告已預先指定子群，將其結論定位為探索性；擴充收案時間或外部院區需另外取得資料與相同判讀。不得事後取消不利子群、修改 ST 門檻或改 OMI 定義來增加陽性。

建模前尚需完成：

1. 核對來源陽性患者、重複 ECG、時間交集與患者內標籤範圍。
2. 取得波形並確認導程、尺度、原始／median 對應與品質覆蓋，固定品質與拒答規則。
3. 完成相鄰導程及例外型態手冊、判讀人員與盲判流程，取得實際子群分母。
4. 釐清事件／時間關係並固定 index ECG；若資料不足，明確限縮為 ECG 層級工程基準。
5. 按實際分母完成樣本精度與患者切分、凍結模型／校準／驗證方案。若要宣稱完整 OMI 或急診首次 ECG 能力，另補 composite 與到院時間資料。

此階段的成果目標是可重現的資料與標註流程、可靠的對照及真實分類效能；尚不承諾超越既有 OMI 模型或獲獎。
