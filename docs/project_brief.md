# 研究題目與目標

題目：**重症患者循環風險預警：結合 HRV 趨勢與訊號品質評估**。

英文：**HRV Trends and Signal Quality for Early Warning of Circulatory Risk in ICU Patients**。

專案由王獻霆、姚亦俠、黃榆崴與李奕辰自主組隊共同開發，指導教授為歐陽彥正教授。成員就讀單位與年級見 [team.md](team.md)。團隊名稱與正式分工待確認；專案歸屬為自主團隊。

第一版目標是完成可驗證、可展示的回溯研究原型，供 2026 生醫電資創新設計競賽使用。後續論文以實際證據與額外驗證為基礎擴充。

## 要解決的問題

床邊監測累積許多 ECG 與生命徵象資料。本研究測試：由 ECG 計算的 HRV，以及同一患者的歷史變化，能否在常規心率和血壓之外提供額外的早期風險資訊。候選使用者為 ICU 團隊，展示重點是重新評估患者的資訊，不輸出用藥建議。

第一個可從資料核對的研究終點是「首次持續升壓劑輸注的開始」。它同時反映患者狀態與臨床決策，不等於未被觀察到的治療需求，也不等同 Sepsis-3 的敗血性休克定義。參考 [Sepsis-3 原始研究](https://jamanetwork.com/journals/jama/fullarticle/2492876)。

## 為什麼選這個範圍

目前可讀的 MIMIC-III 有 23,620 次純 MetaVision ICU 紀錄，其中 7,242 位患者的 ID 出現在連續波形索引。這是資料可行性的起點；成人、事件前時窗與品質篩選後人數仍待確認。MetaVision 的給藥起訖時間較適合先建立持續輸注事件。

第一版主要族群為成人 ICU，敗血症為預先指定的事後描述子群。出院 ICD 診斷不能當成即時預警的納入條件。未來疾病專用版本可以重用讀取、HRV 與評估程式，但要重新定義當下可取得的疾病條件。

## 研究貢獻假設

既有研究已用 HRV／血壓／脈搏波預測休克，也已有 EHR 預測升壓劑啟用；不能主張這些想法首次出現。本專案要實際檢驗三件事：

1. 在逐時、自然事件比例的風險集合中，HRV 是否提供超過常規生命徵象的增益。
2. 在相同歷史資料長度下，趨勢是否比直接加入歷史數值更有幫助。
3. 當 ECG 缺失或品質不佳時，拒絕出分是否能降低不可靠警報，其代價是漏掉多少監測時間與事件。

前兩項若沒有增益，仍完整報告；不以更換資料切分或挑選種子追求高分。主要前作見 [references.md](references.md)。

## 驗收標準

| 交付物 | 驗收證據 |
|---|---|
| 資料與隊列 | 從原始資料可重跑；患者、住院、ICU、波形時間對齊；逐階段排除數與事件數 |
| 標籤 | 有效輸注事件抽查；起訖、重疊、修訂、bolus 與追蹤不足的測試 |
| 訊號處理 | 原始 ECG 品質、節律適用性與資料覆蓋率分開回報；保留失敗原因 |
| 模型比較 | 相同患者切分與風險集合；常規資訊、HRV、歷史、趨勢的增量比較 |
| 驗證 | 患者隔離的保留測試、AUPRC、校準、事件敏感度、誤報率、提前時間、覆蓋率及不確定區間 |
| 展示 | 可重播的風險時間軸；真實研究結果與合成展示資料清楚標示 |
| 競賽材料 | 英文兩頁內摘要、學生本人配音的五分鐘內影片、對照評分項目的證據 |

不預設一個必須達成的 AUROC，也不把現有舊專案或其他文獻的成績當成本專案成績。若保留測試事件數不足以支撐穩定結論，成果定位為可行性與探索性驗證。
